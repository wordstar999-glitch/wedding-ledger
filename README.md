# 웨딩 축의금 장부

예식 당일 축의대에서 일련번호와 금액만 빠르게 입력·저장하는 오프라인 PWA.

- 입력: 일련번호(자동 +1), 금액 프리셋(기본 3·5·10·15·20·30·50만, 설정에서 변경), 직접 입력(만원)
- 정산: 총 건수/총 금액, 목록 수정·삭제, 이름·비고 입력
- 내보내기: .xlsx 저장
- 데이터는 기기의 IndexedDB에만 저장된다.

## 수정 규칙
`sw.js`의 `CACHE_NAME`(`gift-vN`)과 `index.html`의 `APP_VERSION`(`vN`)을 같은 값으로 올려야 설치된 앱에 변경이 반영된다. 값이 다르면 배포가 중단된다.

## 일련번호 규칙
- 일련번호는 키이므로 삭제하지 않는다. 삭제는 내용만 비우고 `(삭제됨)`으로 표시하며, 금액을 다시 입력하면 복구된다.
- 수정 팝업에서 번호는 변경할 수 없다.
- 앱을 열 때 1~지금까지 쓴 최대 번호 중 빠진 번호가 있으면 `(삭제됨)`으로 복구한다.
- 엑셀에는 삭제된 번호도 포함된다(금액 빈칸, 비고 `삭제됨`).

## 백업 · 복원 · 새로 시작
- 설정 탭에서 JSON 백업 저장, 복원(전체 교체), 새로 시작(모든 내역 초기화, 설정 유지)을 할 수 있다.
- 복원과 새로 시작 전에는 현재 내용이 자동으로 백업 파일로 내려받아진다.
- 백업 파일에는 하객 이름·금액이 평문으로 들어 있다.

## 행사 정보와 파일 이름
- 설정의 `행사 정보`에 행사 이름·날짜를 입력하면 백업·엑셀 파일 이름, 정산 화면, 복원 미리보기에 표시된다.
- 파일 이름: `행사이름_백업_행사날짜_저장일시.json`, `행사이름_정산_행사날짜.xlsx` (이름이 없으면 `축의금`, 날짜가 없으면 입력 시작일).
- 복원 전에 불러올 백업과 현재 장부를 비교하는 미리보기가 표시된다.

## 백업 보관함
- 백업 저장과 복원·초기화 직전 자동 백업은 파일로 내려받는 동시에 앱 안에도 최근 10개까지 보관한다.
- 설정의 `복원`을 누르면 보관함 목록(최근 3개, `더 보기`로 전체)이 나오고, 목록에서 골라 복원 미리보기를 거쳐 복원한다. 외부 파일은 `파일에서 선택`.
- 보관함은 앱 데이터와 함께 지워지므로 파일 백업도 따로 보관해야 한다.

## 앱 열기와 업데이트
- 앱은 저장된 화면을 즉시 열고, 새 버전은 뒤에서 받아 다음에 열 때 적용한다(서버가 느려도 바로 열림).
- 새 버전이 있으면 안내 문구가 표시되고, 설정의 `업데이트 확인`으로 바로 적용할 수도 있다.

## 금액 자동 저장과 화면 색상
- 이름은 말하기로 입력하면 인식이 끝난 0.1초 뒤 자동 저장되고, 키보드로 입력할 때는 저장 버튼을 눌러야 저장된다.
- 금액 버튼을 누르면 바로 저장하고, 직접 입력은 입력이 끝난 뒤 저장 버튼(또는 완료 키)을 눌러야 저장한다. 저장 직후 3초 동안 `취소`할 수 있다(번호는 삭제되지 않고 같은 번호로 다시 입력). 설정 > 자동 저장에서 끌 수 있다.
- 설정 > 화면 색상에서 8가지 테마 중 선택한다(기기에 저장, 백업에 포함).
- 브라우저에서 열면 `앱 설치` 띠가 표시되어 한 번 눌러 설치 확인창을 띄운다.

## 도움말과 색상
- 좌측 상단 ☰ 로 도움말(입력·정산·설정·기타)을 연다. 현재 탭의 도움말이 자동으로 펼쳐진다.
- 화면 색상 테마는 하늘 파랑, 맑은 하늘, 민트, 레몬 옐로, 코랄, 청록, 바다 청색, 로즈 핑크. 밝은 테마는 버튼 위 글자를 진한 색(--on-accent)으로 쓴다.

## 환경별 설치 안내
- 브라우저에서 열면 환경(Android Chrome·카카오톡/네이버 등 인앱·iPhone·삼성 인터넷)에 맞는 설치 안내 띠가 나온다. 인앱 브라우저(Android)는 `Chrome으로 열기` 버튼(intent 주소)을 제공한다.
- 설정 > 앱 버전에서 설치 상태를 볼 수 있다.

## 백업 저장과 파일 내보내기
- `백업 저장`과 복원·초기화 직전 자동 백업은 앱 안 보관함에만 저장한다(다운로드 알림 없음).
- `파일로 내보내기`는 JSON 파일을 다운로드한다. 엑셀 저장 직후 파일 백업 안내가 표시된다.
- 보관함은 앱 데이터와 함께 사라지므로 행사가 끝나면 파일로 내보내 밖에 보관해야 한다.
