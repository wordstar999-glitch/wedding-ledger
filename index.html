    앱 버전
    도움말
    입력
    • 금액 버튼을 누르면 바로 저장됩니다.
    • 번호는 저장할 때마다 자동으로 올라갑니다. 바꾸려면 번호 칸을 누르세요.
    • 없는 금액은 '직접 입력'에 만원 단위로 쓰세요. 예: 7 → 7만원
    • 잘못 눌렀다면 '이전 수정'을 누르면 방금 저장한 번호를 고칠 수 있고, 정산 탭에서 번호를 찾아 수정해도 됩니다.
    • 이름과 수정은 정산 탭에서 합니다.
    정산
    • 항목을 누르면 이름·금액·비고를 고칠 수 있습니다.
    • 말하기 입력은 인터넷이 필요합니다.
    • 말하기로 이름을 입력하면 0.1초 뒤 자동 저장되고 다음 빈 항목이 열립니다. 키보드로 입력할 때는 저장 버튼을 누르세요.
    • 동명이인 버튼을 누르면 동명이인만 모아 표시하고, 이름 옆에 '동명'이 붙습니다.
    • 엑셀 저장: 번호·이름·금액·비고를 표로 저장합니다. 정리하거나 보낼 때 쓰세요. 앱으로 다시 불러올 수는 없습니다.
    • 백업 저장: 지금 장부를 앱 안에 사본으로 저장합니다. 잘못 고치거나 지웠을 때 복원에 씁니다.
    • 체킹 완료: 봉투와 금액을 대조했으면 항목을 눌러 '체킹 완료'를 켜고 저장하세요. 목록에 ✓가 붙습니다.
    • 체킹완료 버튼은 누를 때마다 완료만 → 체킹 안 된 것만 → 전체로 바뀝니다.
    • 삭제해도 번호는 남습니다. 금액을 다시 입력하면 되살아납니다.
    설정
    • 행사 정보에 이름과 날짜를 적어 두세요. 파일 이름에 들어갑니다.
    • 백업 저장: 이 폰의 이 앱 안에 사본을 저장합니다. (최근 10개)
    • 복원: 앱 안의 사본으로 되돌립니다.
    • 백업 파일 내보내기: 폰의 다운로드 폴더에 백업 파일로 저장합니다. 앱을 지워도 남습니다.
    • 행사 중간엔 백업 저장, 끝나면 백업 파일 내보내기를 꼭 하세요.
    기타
    • 설치는 전달받은 주소를 클릭하면 할 수 있습니다.
    • 인터넷이 없어도 쓸 수 있습니다. 말하기 입력만 인터넷이 필요합니다.
    • 장부는 이 휴대폰에만 저장됩니다. 앱을 지우면 사라지니 백업 파일을 내보내 두세요.
    • 엑셀 파일은 보는 용도이고, 백업 파일은 되돌리는 용도입니다.
    • 새 버전은 앱을 두 번 열면 적용됩니다.

    백업 보관함

    앱을 지우면 보관함도 사라집니다. 파일 백업도 따로 보관하세요.
